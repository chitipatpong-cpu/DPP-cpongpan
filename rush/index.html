✨ Elemental Mechanics

ศาสตร์แห่ง 7 ธาตุและปฏิกิริยาพลิกแพลง

หัวใจของการต่อสู้ใน Teyvat คือการผสานพลังธาตุเพื่อสร้างความเสียหายทวีคูณ ควบคุมศัตรู หรือลดเกราะป้องกัน ลองเลือกคู่ธาตุในเครื่องคำนวณด้านล่างเพื่อดูผลลัพธ์

  • 🔥Pyroไฟ (เผาและขยายดาเมจ)
  • 💧Hydroน้ำ (ทำให้เปียก)
  • ⚡Electroสายฟ้า (ช็อตต่อเนื่อง)
  • ❄️Cryoน้ำแข็ง (ทำให้เย็น/แช่แข็ง)
  • 🍃Anemoลม (กระจาย Swirl)
  • 💎Geoหิน (ผลึกโล่)
  • 🌿Dendroพืช (ผลิบาน/เร่งโต)

⚗️ Reaction Calculator (เครื่องคำนวณปฏิกิริยา)

📋 ตารางสรุปปฏิกิริยาธาตุยอดนิยมสำหรับผู้เริ่มต้น (Quick Cheat Sheet)

ปฏิกิริยา (Reaction) ธาตุที่ผสมผสาน ผลของสถานะ / รูปแบบดาเมจ คำแนะนำสำหรับมือใหม่
Vaporize (ระเหย) Pyro + Hydro คูณความเสียหาย 1.5x ถึง 2.0x ดาเมจเป้าหมายเดี่ยวแรงมาก เหมาะกับการสู้บอส
Melt (ละลาย) Pyro + Cryo คูณความเสียหาย 1.5x ถึง 2.0x Pyro ใส่เป้าหมายที่ติด Cryo ได้ 2.0x ตัวเลขคริติคอลสูงมาก
Vaporize (ระเหย) Pyro + Hydro คูณความเสียหาย 1.5x ถึง 2.0x ดาเมจเป้าหมายเดี่ยวแรงมาก เหมาะกับการสู้บอส
Melt (ละลาย) Pyro + Cryo คูณความเสียหาย 1.5x ถึง 2.0x Pyro ใส่เป้าหมายที่ติด Cryo ได้ 2.0x ตัวเลขคริติคอลสูงมาก
Freeze (แช่แข็ง) Hydro + Cryo ศัตรูถูกล็อกขยับไม่ได้ชั่วคราว คุมมอนสเตอร์เป็นกลุ่มให้อยู่นิ่ง ปลอดภัยสำหรับมือใหม่
Electro-Charged (ชาร์จไฟ) Hydro + Electro ไฟฟ้าช็อตต่อเนื่อง กระโดดไปหาศัตรูที่เปียกน้ำรอบข้าง ทำให้ศัตรูชะงักบ่อย เหมาะกับการกวาดมอนสเตอร์ฝูงใหญ่
Bloom / Hyperbloom Dendro + Hydro (+ Electro) สร้างเมล็ดพืช แล้วยิงจรวดติดตามศัตรู ยิ่งมีค่า Elemental Mastery สูง ดาเมจยิ่งแรง
Swirl (กระจาย) Anemo + Pyro / Hydro / Electro / Cryo กระจายธาตุเป็นวงกว้าง ใช้ไม่ได้กับ Geo และ Dendro เซ็ตอาร์ติแฟกต์ Viridescent Venerer 4 ชิ้นช่วยลดการต้านทานธาตุของศัตรูลง 40%
Crystallize (ตกผลึก) Geo + Pyro / Hydro / Electro / Cryo สร้างผลึกให้เก็บเพื่อได้โล่ธาตุ เดินไปเก็บผลึกระหว่างสู้ เพื่อรับโล่ป้องกันความเสียหาย
